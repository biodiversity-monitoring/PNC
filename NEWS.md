# PNC 0.2.0 (2026-08-28)

* Redesigned `pnc()` and `compnc()` for a simpler and more consistent analysis workflow.
* Standardized outputs and updated `n_sp` to reflect the actual number of species used in each analysis.
* Improved `pnc_robustness()` and `compnc_robustness()` using paired simulations to evaluate sensitivity to observed missing-data patterns.
* Added `consistency`, `signal_bias`, `signal_sd`, and `n_successful` to robustness outputs.
* Revised function documentation and examples.
